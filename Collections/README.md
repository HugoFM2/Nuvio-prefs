# Coleções do NUvio

Este diretório armazena os dados e os recursos visuais para as coleções do repositório.

## Padrão de Imagem da Coleção

Para manter a uniformidade visual do repositório, todas as imagens de capa das coleções devem ser criadas seguindo estritamente as diretrizes abaixo:

* **Ferramenta de Edição:** Pixlr (Versão Web)
* **Tamanho do Canvas (Resolução):** 1280 x 720 pixels
* **Tipografia (Fonte):** Halenoir Expanded Extra Bold
* **Tamanho da Fonte:** 140
